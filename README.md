# Senith Dakshina Portfolio

Professional portfolio website for Senith Dakshina, a Computer Science and Technology undergraduate focused on full-stack software engineering.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React

## Scripts

```bash
npm run dev
npm run lint
npm run build
```

## Contact Form Setup

Create a `.env` file from `.env.example` and add your Web3Forms access key:

```bash
VITE_WEB3FORMS_ACCESS_KEY=your_web3forms_access_key_here
```

After that, the contact form sends messages directly from the website without opening the visitor's email app.
